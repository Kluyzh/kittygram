# Kittygram - социальная сеть для размещение фотографий домашних животных.

## Описание проекта
Проект, где пользователи могут регистрироваться, загружать фотографии кошек с описанием их достижений, а также любоваться на других котов.

## Технологии
• Python 3.9
• Django==3.2.3
• djangorestframework==3.12.4
• nginx
• djoser==2.1.0

## Что cделано:

- Настроен запуск проекта Kittygram в контейнерах и CI/CD с помощью GitHub Actions
- Пуш в ветку main запускает линтеры, тестирование, сборк и деплой Kittygram, а после успешного деплоя вам приходит сообщение в телеграм.
- В корне проекта есть файл `kittygram_workflow.yml`.

### Как запустить проект:
Клонировать репозиторий и перейти в него в командной строке:

```
git clone <https or SSH URL>
```
Создать файл .evn для хранения ключей в корне проекта:

```
SECRET_KEY='указать секретный ключ'
ALLOWED_HOSTS='указать имя,IP хоста,"backend"'
POSTGRES_DB: django_db
POSTGRES_USER: django_user
POSTGRES_PASSWORD: django_password
DB_HOST=db
DB_PORT=5432
DEBUG=False
```

Из основной директории
```
docker compose up -d
```
Сайт доступен
```
http://127.0.0.1:9000/
```
